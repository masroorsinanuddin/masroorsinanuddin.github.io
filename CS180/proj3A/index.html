The hardest part of this was creating the canvas. At first, I was able to fairly easily get the image in such a way that I rectify the square/rectangle that I wanted to, but in the rectification, everything was cropped besides the actual square/rectangle itself.

What I had to do to create this bigger canvas was first create a homography on the main subject of my image, which is usually a rectangle/square, by mapping the 4 corners into 4 points that actually do define a rectangle/square (note that I did not bother preserving the aspect ratio for the sake of time. I ended up using the following coordinates for the output rectangle: [[0,0],[0,301],[402,301],[402,0]]. I made this decision before I fully realized what I was doing, and at that time I was originally trying to map the subject of my image onto the 4 corners of a canvas which i decided to make the exact same size of my image, which was 302 x 403) Then, I had to see where this homography would take the four corners of my original image, and then make a canvas big enough to fit all of the corners into it. Then, I had to find a way to map the image properly into the canvas, which I did by some wierd coordinate translation stuff to make sure that the corners which get mapped, for example, into negative values get translated back into the canvas. The main way I did this was by preserving the most negative x and y values that one of my 4 corners mapped into (roughly speaking, this is not exactly what I did but I do not know how to say what I did properly enough to write it down here), and then I shifted every point transformed under H by that x and y value to bring it back into the coordinate system so that it sits within the canvas.

Task A4: Panorama

For this task, I had to blend two or more images taken from the same center of projection into a panorama

I have created 3 different panoramas with two images each. I have tried creating the panoramas both via Bilinear Interpolation method (pano_BI) and via Nearest Neighbor (pano_NN).

Panorama 1

The hardest part of this was creating the canvas. For the sake of getting part A of this project done on time, i just kind of cheated my way around it and created a mega big canvas. The mega canvas was just padding my base image with 500 zeros to the top, bottom, right, and left. I then selected corresponding points between the image that I wanted to warp, and the points in the base image within the canvas (I had to use the canvas, and not the original base image itself because I was projecting the second image onto the canvas rather than the original base image) I then computing the Homography matrix, and went through the entire mapping procedure. However, I did not directly map the second image to the canvas (although in hind sight, maybe I could have). Instead, I mapped it onto an empty canvas that had the same dimensions as the first canvas. The idea is that now I have two canvases, one with each image, and if I combine them in some way, I would get the final image. In order to combine them, I had to account for an extra detail: the alpha values

Dealing with the alpha values was another fairly difficult task (but not as difficult cuz I kinda quickly gave up on it and hacked my way around it). Again, for the sake of getting part A done in time, I also hacked my way around this and just created a seperate image matrix called alpha_values This alpha_values matrix had the same dimensions as the canvas, and was initiated to zero in all three of its color channels in every point, except for the points where the base image was on the canvas. At those points, the alpha_values matrix had a value of one. When I mapped the warp image onto the blank canvas, each time I put a point from my warped image into the blank canvas, I had to track which coordinates on the blank canvas the warped image was being put into, and I found the corresponding point in the alpha matrix and added one to it.

In the end, I did an elementwise sum of the two canvases together, and then an elementwise division by the alpha matrix (numpy seemed to automatically deal with the zero division error, which was very helpful)

Task B3: Feature Matching

For this task, I matched feature descriptors between image pairs using the ratio test from Lowe's method. I computed the nearest neighbors and thresholded based on the ratio of the first to second nearest neighbor distances.
