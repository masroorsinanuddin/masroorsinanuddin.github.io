Task A3: Image Rectification

I rectified a photo of a square taken from an angled perspective to make it appear frontal, using both Bilinear Interpolation (rectified_BI) and Nearest Neighbor (rectified_NN) methods.

Below are the rectified images (presentation to be improved for final submission).

Rectification 1 (Bilinear Interpolation)
Rectification 2 (Nearest Neighbor)

The main challenge was creating a canvas large enough to avoid cropping. Initially, rectification only preserved the square, losing the rest of the image. To fix this, I mapped the four corners of the original image under the homography, determined the bounding box of the projected corners, and created a canvas to fit all points. I applied a translation to handle negative coordinates, shifting the warped image to fit within the canvas. The target rectangle coordinates were \([[0, 0], [0, 301], [402, 301], [402, 0]]\) (chosen to match the image size 302x403 without preserving aspect ratio for simplicity).

Task A4: Panorama

I created panoramas by blending two images taken from the same center of projection, using both Bilinear Interpolation (pano_BI) and Nearest Neighbor (pano_NN) methods. Three panoramas were produced.

Below are the results (presentation to be improved for final submission).

Panorama 1 (Bilinear Interpolation)
Panorama 2 (Nearest Neighbor)
Panorama 3 (Bilinear Interpolation)

The canvas size was a challenge. For Part A, I used a large canvas (padding the base image with 500 pixels on all sides) to avoid complex calculations. I selected corresponding points between the images, computed the homography, and warped the second image onto a separate canvas matching the first canvas's size. To blend, I used an alpha matrix to track non-zero pixels in both images, setting alpha to 1 for the base image and incrementing it for warped image pixels. The final panorama was an element-wise sum of the canvases divided by the alpha matrix, handling overlaps (NumPy managed zero-division errors).

Part B: Automatic Image Stitching

Part B focuses on automating the panorama stitching process by implementing feature detection, description, matching, and robust homography estimation, following the paper "Multi-Image Matching using Multi-Scale Oriented Patches" by Brown et al. (simplified to single-scale, non-rotation-invariant descriptors).

Task B1: Harris Corner Detection

I implemented the Harris Corner Detector using provided code (`harris.py`) to detect interest points in an image, following Section 2 of the paper (single-scale, no sub-pixel accuracy). I also implemented Adaptive Non-Maximal Suppression (ANMS, Section 3) to select a well-distributed subset of corners, though I initially tested with random corner selection before completing ANMS.

Below are the detected corners overlaid on Image 1, with and without ANMS.

Harris Corners without ANMS
Harris Corners with ANMS

The ANMS step ensured better spatial distribution of corners, reducing clustering in high-contrast areas. This was achieved by suppressing weaker corners within a radius proportional to their strength, as described in Section 3 of the paper.

Task B2: Feature Descriptor Extraction

I extracted feature descriptors for each Harris corner, following Section 4 of the paper (simplified to axis-aligned 8x8 patches without rotation invariance). Each descriptor was sampled from a 40x40 window around the corner, blurred to reduce noise, and normalized for bias and gain to ensure robustness to lighting changes.

Below are examples of extracted 8x8 feature patches from Image 1.

The 40x40 window was critical for capturing sufficient context, and normalization ensured descriptors were comparable across images. I skipped the wavelet transform as instructed.

Task B3: Feature Matching

I implemented feature matching between two images, following Section 5 of the paper. Matches were identified by computing the Euclidean distance between 8x8 descriptors and applying Lowe’s ratio test (thresholding the ratio of the first to second nearest neighbor distances, inspired by Figure 6b in the paper).

Below are examples of matched features between Image 1 and Image 2.

Feature Matches (Image 1 to Image 2)

The ratio test effectively filtered out ambiguous matches, ensuring only high-confidence correspondences were used for homography estimation.

Task B4: RANSAC for Robust Homography

I implemented 4-point RANSAC from scratch to compute robust homography estimates, using the feature matches from Task B3. The algorithm iteratively samples four matches, computes a homography, and evaluates it based on the number of inliers (points with low reprojection error). The best homography was used to stitch images into mosaics, adapting the canvas creation and blending code from Task A4.

RANSAC significantly improved robustness compared to manual point selection, handling outliers in feature matches effectively.
