class Convolution:
    def __init__(self, path, kernel):
        if np.ndim(kernel) != 2:
            raise TypeError("kernel must be a matrix (a 2d array) \n for a '1D' kernel, just wrap your kernel around another set of brackets")
        else:
            self.im_path = path
            self.image = ski.io.imread(path, as_gray=True)
            self.kernel = kernel
            self.flipped_kernel = [row[::-1] for row in kernel][::-1]

    def convolve4(self):
        image = ski.img_as_float(self.image)
        print(np.min(image), np.max(image))
        extension_length_dim1 = len(self.flipped_kernel)//2
        extension_length_dim2 = len(self.flipped_kernel[0])//2
        padded_image = np.pad(image, pad_width=((extension_length_dim1, extension_length_dim1), (extension_length_dim2, extension_length_dim2)), mode='constant')
        rVal = (padded_image - padded_image)//1.0
        for image_row in range(extension_length_dim1, extension_length_dim1 + len(image)):
            for image_col in range(extension_length_dim2, extension_length_dim2 + len(image[0])):
                for kernel_dim1_offset in range(-1*(extension_length_dim1), 1 + extension_length_dim1):
                    for kernel_dim2_offset in range(-1*(extension_length_dim2), 1 + extension_length_dim2):
                        rVal[image_row][image_col] += padded_image[image_row + kernel_dim1_offset][image_col + kernel_dim2_offset] * self.flipped_kernel[kernel_dim1_offset + extension_length_dim1][kernel_dim2_offset + extension_length_dim2]
        return np.array([column[extension_length_dim2:extension_length_dim2 + len(image[0])] for column in rVal[extension_length_dim1:extension_length_dim1 + len(image)]])

class Convolution:
    def __init__(self, path, kernel):
        if np.ndim(kernel) != 2:
            raise TypeError("kernel must be a matrix (a 2d array) \n for a '1D' kernel, just wrap your kernel around another set of brackets")
        else:
            self.im_path = path
            self.image = ski.io.imread(path, as_gray=True)
            self.kernel = kernel
            self.flipped_kernel = [row[::-1] for row in kernel][::-1]

    def convolve2(self):
        image = self.image
        img_extension_length_dim1 = len(self.flipped_kernel)//2
        img_extension_length_dim2 = len(self.flipped_kernel[0])//2
        padded_image = np.pad(image, pad_width=((img_extension_length_dim1, img_extension_length_dim1), (img_extension_length_dim2, img_extension_length_dim2)), mode='constant')
        ker_extension_length_dim1 = len(padded_image) - len(self.flipped_kernel)
        ker_extension_length_dim2 = len(padded_image[0]) - len(self.flipped_kernel[0])
        padded_kernel = np.pad(self.flipped_kernel, pad_width=((0, ker_extension_length_dim1), (0, ker_extension_length_dim2)))
        rVal = (padded_image - padded_image)//1.0
        for image_row in range(img_extension_length_dim1, img_extension_length_dim1 + len(image)):
            padded_kernel_colRol = padded_kernel
            for image_col in range(img_extension_length_dim2, img_extension_length_dim2 + len(image[0])):
                rVal[image_row][image_col] += np.sum(padded_image * padded_kernel_colRol)
                padded_kernel_colRol = np.roll(padded_kernel_colRol, 1, axis=1)
            padded_kernel = np.roll(padded_kernel, 1, axis=0)
        return np.array([column[img_extension_length_dim2:img_extension_length_dim2 + len(image[0])] for column in rVal[img_extension_length_dim1:img_extension_length_dim1 + len(image)]])

Task 1.3: Derivative of Gaussian Filter

For this task, there is 2 parts.

The first part is to recreate the gradient magnitude image, except after having blurred the image with a gaussian. The second part is to recreate the gradient magnitude image once more, except by creating "DoG" filters. DoG stands for Derivaitve of Gaussian. The idea is to first convolve the gaussian with the finite difference filters, once for Dx and once for Dy, and then apply each of those to the original image and find the gradient magnitude from there.

Both strategies should lead to the same results, and also lead to a better results of reducing noise while retaining key information about the image better than binarizing our un-blurred gradient magnitude image did

Task 2.1: Image Sharpening

For this task, I had to "sharpen" an image. The way to go about this is to add more high frequencies to the image. We can get these high frequencies by blurring the image with our Gaussian filter, and then subtracting the image from the blurred image. This will leave us with an image that contains only the high frequencies of the original image. Let us call this the "sharpener" Then, we can take that sharpener and add it to the image \(\alpha\) number of times to sharpen it like so: \[\text{Sharpened Image} = \text{Image} + \alpha \cdot \text{Sharpener}\]

Task 2.3: Gaussian and Laplacian Stack, Multiresolution Blending

For this task, I had to merge images via "Multiresolution Blending". At a high level, multiresolution blending is just stitching together two images, and smoothing the transition between them. To understand multiresolution blending, it is important to know what a Laplacian and a Gaussian stack

A "Laplacian stack" is just a stack of the image split up into different frequency bands, where the frequencies get higher as you go higher up the stack, with the base containing all the frequency left overs. The way I have constructed this stack is by creating a "Gaussian Stack", which is the same thing but you are getting lower frequencies the higher up the stack you go. Then, I get an element of the stack and subtract it off from the less blurry image that is one element lower in the stack, and I end up with the high frequency difference between them (i.e the frequencies that were present in the less blurry element above my current element) Essentially, each element in my laplacian stack is a "band pass" image, i.e it is the noise in between elements of the gaussian stack. One final thing to note here is that at the bottom of your gaussian stack, your laplacian and your gaussian will be the same (that is the image that contains all the frequency left overs.)

When preforming multiresolution blending, you need two images, so you will construct a laplacian stack for the both of them. You also need to have a mask to define where one image should end and the other should begin. You should create a gaussian stack of your mask in parallel to your image. In the end, you have three stacks: a laplacian stack of your first image, a laplacian stack of your second image, and a gaussian stack of your mask.

Now that you have these three stacks, what you do is first, take an elementwise multiplication of the mask stack with the laplacian stack of image 1, and the same with (1- mask stack) and the laplacian stack of image 2. Then, you do elementwise addition of the resulting two stacks. Finally, you collapse the stack by adding all the elements together (and in the end normalizing/clipping if necessary)
