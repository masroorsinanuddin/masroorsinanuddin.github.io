Implementation Summary

Brief description of the implementation for ray sampling, network training, and rendering pipeline.

Majority of of my code has been batched by along its zeroeth dimension by cameras, and along first dimension by rays per camera, and (for some tasks), along the third dimension for number of points per Ray

Creating Rays from Camera

I created a function with the signiture: 


    def transform(self, c2w_transformations, rays):
        """
        Purpose:
        transform a batch of rays [C, R, 3] from camera coordinates to the world coordinates

        Inputs:
        - "c2w_transformations" is [C, 4, 4], where C is batch of camera the rays are being sampled from and the [4, 4] is the transformation matrix of each camera
        - "rays" is [C, R, 3] where C is batch of camera the rays are being sampled from, and R is the total number of rays among all the cameras to sample, as in func pixel_to_camera

        Outputs:
        - "rVal" is [C, R, 3] where the rays are now in the perspective of the world coordinate
        """

Pixel to Camera Coordinate Conversion

I created a function with the signiture: 


    def pixel_to_camera(self, uv, s=1):
        """
        Purpose:
        convert a ray from a image plane coordinate (i.e a 2D grid) into a 3D ray in space with respect to the camera coordinate given the camera intrinsics (we do not consider the camera extrinsics in this function)

        Inputs:
        - "uv" [C, R, 2] where C is number of images and R is number of rays sampled per image, and 2 is the coordinates of each ray on the image plane
        - "s" is a scalar. usually set to 1

        Outputs:
        - "cam_coords" is  #[C, R, 3], the camera coordinate representations of the ray (considering a camera with NO REGARD for extensics)
        """

Pixel to Ray

I created a function with the signiture: 


    def pixel_to_ray(self, c2w, uv):
        """
        Purpose:
        Take a 2d array of pixels rays in a camera as well as c2w transformations, 
        and get the rays of each point in world coordinates as well the camera position in world coordinates

        Inputs:
        - "uv" is [C, R, 2] where C is number of images and R is number of rays being sampled per image
        - "c2w" is  [C, 4, 4]  where C is number of images

        Outputs:
        - rays_cam is [C, 3]. It represents the rays of camera coordinates (i.e camera locations)
        - rays_dir is [C, R, 3]. It represents normalized rays of each pixel we sample from that camera
        """

Sampling Rays from Images

I created a function with the signiture: 


    def rand_sample_rays(self, num_rays, num_cameras=None):
        """
        Purpose:
        Randomly choose which cameras to sample from, as well as how many rays to sample per camera

        Input:
        - "num_rays" is R: the number of rays you want to sample per camera, or (if num_cameras is None) number of rays among all cameras
        - "num_cameras" is C: the number of cameras you want to sample from

        Output:
        - this huge dictionary of the following key value pairs:
        -> 'rays_dir': rays_dir [C, R, 3] -- normalized rays of each pixel we sample from that camera
        -> 'rays_cam': rays_cam [C, 3] -- the rays of camera coordinates (i.e camera locations)
        -> 'coords': coords [C, R, 2] -- the pixel coordinates that we sampled
        -> 'coords_normalized': coords_normalized [C, R, 2] -- the pixel coordinates that we sampled, but normalized by height and width of image
        -> 'rand_cams_index': rand_cams_index [C] -- the indexes of each camera that we randomely selected
        -> 'true_colors': true_colors [C, R, 3] -- the colors of each of the randomely sampled pixels
        -> 'true_colors_normalized': true_colors_normalized [C, R, 3] -- the colors of each of the randomley sampled pixels normalized
        """

Sampling Points along Rays

I created a function with the signiture: 


    def sample_along_rays(self, rays_cam, rays_dir, perturb=True, start=near, stop=far, num_points=num_pts_per_ray):

        Purpose:
        Randomely choose which points along ray to sample from

        Input:
        - "rays_cam" is [C, 3] where C is number of camera, 3 is location of each camera
        - "rays_dir" is [C, R, 3] where C is number of camera, R is rays per camera, and 3 points needed to descibe a ray

        Output:
        - "rays_points" is [C, R, N, 3]

Volume Rendering

I created a function with the signiture: 


        """
        Purpose:
        I want to be able to put in the outputs of the MLP into here (rgb, density) 
        along with the distance between points along a ray and get the color of each of those points.

        Inputs:
        - "rgb" is [C, R, N, 3], C for camera, R for rays, N for samples along rays, 3 for each color channel
        - "density" is [C, R, N, 1], C for camera, R for rays, N for samples along rays, 1 for density of point
        - "points" is [C, R, N, 3], C for camera, R for rays, N for samples along rays, 3 for point coordinates
        - "rays_dir" is [C, R, 3], C for camera, R for rays, 3 for direction of ray

        Outputs:
        - "rendered" is [C, R, 3], C for camera, R for rays, and 3 for color. It represents color for each ray
        """
