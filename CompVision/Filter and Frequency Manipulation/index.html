class Convolution:
    def __init__(self, path, kernel):
        if np.ndim(kernel) != 2:
            raise TypeError("kernel must be a matrix (a 2d array) \n for a '1D' kernel, just wrap your kernel around another set of brackets")
        else:
            self.im_path = path
            self.image = ski.io.imread(path, as_gray=True)
            self.kernel = kernel
            self.flipped_kernel = [row[::-1] for row in kernel][::-1]

    def convolve4(self):
        image = ski.img_as_float(self.image)
        print(np.min(image), np.max(image))
        extension_length_dim1 = len(self.flipped_kernel)//2
        extension_length_dim2 = len(self.flipped_kernel[0])//2
        padded_image = np.pad(image, pad_width=((extension_length_dim1, extension_length_dim1), (extension_length_dim2, extension_length_dim2)), mode='constant')
        rVal = (padded_image - padded_image)//1.0
        for image_row in range(extension_length_dim1, extension_length_dim1 + len(image)):
            for image_col in range(extension_length_dim2, extension_length_dim2 + len(image[0])):
                for kernel_dim1_offset in range(-1*(extension_length_dim1), 1 + extension_length_dim1):
                    for kernel_dim2_offset in range(-1*(extension_length_dim2), 1 + extension_length_dim2):
                        rVal[image_row][image_col] += padded_image[image_row + kernel_dim1_offset][image_col + kernel_dim2_offset] * self.flipped_kernel[kernel_dim1_offset + extension_length_dim1][kernel_dim2_offset + extension_length_dim2]
        return np.array([column[extension_length_dim2:extension_length_dim2 + len(image[0])] for column in rVal[extension_length_dim1:extension_length_dim1 + len(image)]])

class Convolution:
    def __init__(self, path, kernel):
        if np.ndim(kernel) != 2:
            raise TypeError("kernel must be a matrix (a 2d array) \n for a '1D' kernel, just wrap your kernel around another set of brackets")
        else:
            self.im_path = path
            self.image = ski.io.imread(path, as_gray=True)
            self.kernel = kernel
            self.flipped_kernel = [row[::-1] for row in kernel][::-1]

    def convolve2(self):
        image = self.image
        img_extension_length_dim1 = len(self.flipped_kernel)//2
        img_extension_length_dim2 = len(self.flipped_kernel[0])//2
        padded_image = np.pad(image, pad_width=((img_extension_length_dim1, img_extension_length_dim1), (img_extension_length_dim2, img_extension_length_dim2)), mode='constant')
        ker_extension_length_dim1 = len(padded_image) - len(self.flipped_kernel)
        ker_extension_length_dim2 = len(padded_image[0]) - len(self.flipped_kernel[0])
        padded_kernel = np.pad(self.flipped_kernel, pad_width=((0, ker_extension_length_dim1), (0, ker_extension_length_dim2)))
        rVal = (padded_image - padded_image)//1.0
        for image_row in range(img_extension_length_dim1, img_extension_length_dim1 + len(image)):
            padded_kernel_colRol = padded_kernel
            for image_col in range(img_extension_length_dim2, img_extension_length_dim2 + len(image[0])):
                rVal[image_row][image_col] += np.sum(padded_image * padded_kernel_colRol)
                padded_kernel_colRol = np.roll(padded_kernel_colRol, 1, axis=1)
            padded_kernel = np.roll(padded_kernel, 1, axis=0)
        return np.array([column[img_extension_length_dim2:img_extension_length_dim2 + len(image[0])] for column in rVal[img_extension_length_dim1:img_extension_length_dim1 + len(image)]])

I noticed that convolution with 4 for-loops took more time than with 2 for-loops, which took more time than scipy.signal.convolve2d. All cases used zero-fill boundaries. The blurring, Dx, and Dy results look identical across methods.

Derivative of Gaussian Filter

There are two parts here.

The first part is to recreate the gradient magnitude image after blurring the image with a gaussian. The second part is to recreate it by creating "DoG" filters (Derivative of Gaussian), convolving the gaussian with finite difference filters for Dx and Dy, then applying them to the original image.

Both strategies lead to similar results, reducing noise while retaining key information better than binarizing the un-blurred gradient magnitude image.

Image Sharpening

Hybrid Images

I created a "hybrid image" using the approach from the SIGGRAPH 2006 paper by Oliva, Torralba, and Schyns.

A hybrid image is a high-frequency image added to a low-frequency one. From a distance, the low-frequency image is visible; up close, the high-frequency one dominates.

Gaussian and Laplacian Stacks, Multiresolution Blending

I merged images via multiresolution blending, which stitches images with smooth transitions. Understanding multiresolution blending requires knowing Gaussian and Laplacian stacks.

A Laplacian stack splits the image into frequency bands, with lower frequencies higher in the stack and the base holding leftovers. I constructed it from a Gaussian stack (lower frequencies higher up), subtracting levels for high-frequency differences. Each Laplacian element is a band-pass image, capturing noise between Gaussian levels. At the stack bottom, Laplacian and Gaussian are the same (containing frequency leftovers).

For multiresolution blending, construct Laplacian stacks for two images. Use a mask defining where one image ends and the other begins. Create a Gaussian stack of the mask parallel to the images. Result: Laplacian stacks for images and Gaussian stack for mask.

Multiply mask stack with first image's Laplacian, (1-mask) with second. Add resulting stacks elementwise. Collapse by summing all elements (normalize/clip if needed).

Closing Remarks

I learned about image frequency composition, human perception, and manipulating images creatively.

Each image requires unique handling. For efficiency, I normalized all in later sections, but histograms showed clipping often sufficed for better output.

Finite difference operators with Gaussian were interesting for highlighting key features.

Hybrid images were fascinating, applying frequency perception practically.

Overall, I enjoyed exploring these techniques and look forward to more.
