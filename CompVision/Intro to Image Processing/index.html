Image Alignment Experiments

Single-Scale Alignment

I explored aligning the red, green, and blue channels of an image to create a cohesive picture. I chose the blue channel as the base and aligned the red and green channels to it. For single-scale alignment, I used pixel intensity for alignment, assuming the color channels have similar intensities at corresponding points. I applied the normalized cross-correlation (NCC) metric to measure similarity between images. Higher NCC values indicate better alignment. Here’s the NCC formula I used:

To save computation time, I aligned only the middle 40% of the image. This wasn’t critical for single-scale alignment but became important for larger images in multi-scale alignment. One challenge was handling the “ledge” when sliding one image over another. Since NCC requires aligned image corners for the dot product, I used the np.roll() function to shift the image. However, this caused “overflow” where shifted pixels wrapped around to the other side, which could skew NCC results. To fix this, I applied a masking matrix to the sliding image, setting border pixels to zero to prevent overflow from affecting the correlation.

The offsets for aligning each color channel are listed below each image. The blue channel offset is always (0, 0) since it’s the base channel, with red and green aligned to it.

Multi-Scale Pyramid Alignment

For larger images, direct NCC was too slow. Instead, I used an image pyramid, which recursively reduces image size with a Gaussian filter until it’s small enough for efficient computation. This allowed me to perform most calculations on the smallest image, then adjust as I scaled back up to larger sizes. Here’s a visual of an image pyramid:

The image pyramid was fairly efficient compared to direct NCC, but it still took 90–120 seconds. To speed things up, I reduced the NCC search window by a factor of 2 at each pyramid level as I scaled up. This caused issues with some images, like emir.tif and melon.tif, as seen below. To improve results, I switched to aligning based on edges rather than pixel intensity, since edges are more likely to be consistent across color channels. I used the Sobel filter from skimage to detect edges, which calculates pixel intensity derivatives. It assigns high values to areas with sharp intensity increases and low values to decreases, effectively highlighting edges. The Sobel filter convolves the image with these kernels to compute x and y partial derivatives, then combines them into a single edge map using the magnitude function. I applied NCC to this edge map instead of raw pixel intensities.
